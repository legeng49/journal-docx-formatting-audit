# 科技期刊论文表述收紧与禁用套话审查清单

## 1. 必须清零的拿腔用词与替换原则

| 禁用词/套话 | 问题诊断 | 规范修改方式 |
| :--- | :--- | :--- |
| `揭示了`、`直接印证`、`印证了`、`刚性前置约束` | 过度拔高或拿腔作势 | 直接删去，由公式编号与定量对比数据直接说明关系（如“该过程与第2.2节的分析一致”“在给定持续回补期限内对比各候选方案”）。 |
| `清晰解耦`、`精确刻画` | 空泛主观形容词 | 直接写出模型保留了哪些具体物理状态与通路（如“该平均模型保留了转子动能、机侧取电、网侧送电和直流母线能量动态”）。 |
| `显著收缩`、`显著偏离`、`显著扩大`、`显著降低`、`更显著的` | 含糊修饰词 | 有具体数值的地方直接写数值（如“可用动能裕度降至 0.902 5 MJ”“扩大 12.82 mHz”）；无量化对比处删去“显著”（改写为“更大的峰谷落差”）。 |
| `更为关键的是`、`综合上述`、`可以看出`、`可以看到` | 冗余过渡套话 | 句首或段首删去套话，直接进入主语和定量结果（如“在图5(a)中，系统频率越过首次谷点……”）。 |
| `源—网—储` | 概念口号化泛指 | 具体写明物理环节：“风机减发、储能放电和常规下垂”。 |
| `不仅体现在……更取决于……` | 口语化递进套话 | 直接陈述将恢复缺口与一次调频置于同一暂态时间窗口内开展闭环评估。 |

## 2. 必须收紧的重复判断与免责声明

1. **摘要末句**：当摘要前文已给出核心定量对比结果（如 `4.32 mHz`、`12.82 mHz`）时，删去末尾空洞的“研究表明，转速恢复整定应在满足回补期限的前提下统筹……”总结套话。
2. **引言末段**：不在引言中提前罗列否定式定性结论（如“缩短回补时间并非必然减小峰后波动；提高补偿比例并非必然同步改善低点和峰谷差”），改为直接陈述本文建立的模型、方法以及核心定量结果（`4.32 mHz`、`12.82 mHz`、`5.41 mHz`），将机理解释留给第 1、2 节。
3. **跨章节重复句去重**：
   - 如“交接动能欠额不足以单独决定累计缺口与频率回落幅值”在全文只保留在式(9)全网净有功缺额积分处一次，删去式(8)后和结论 1 中的重复句。
   - 储能机理段末删去与引言/算例重复的“名义补偿比例并非决定频率调控效果的充分条件”。
   - 图 7 解读段末删去“单纯削减风电并网功率缺口不足以保证峰谷频率波动同步收敛”免责声明（表 3 已给出具体毫赫兹增幅）。
4. **离散候选优选表述**：直接写候选值（如 `0.35 MW/MJ`）在满足期限的离散候选中取得最小峰谷回落，不额外添加“非全局最优”等过度防御字眼。

## 3. 必须保留的物理前提与模型适用边界

在删繁就简的同时，以下四类关键物理假设与模型边界必须准确保留且只在对应位置出现一次：
1. **简化近似成立条件**（如式(7)后）：仅当气动输入近似恒定且直流母线电容能量变化可忽略时，送网缺口才近似等于转子动能回补功率 $P_{\mathrm{gap}}\approx -\dot{E}_d$。
2. **可行域必要下界前提**（如式(11)处）：忽略非最优叶尖速比捕风损失且直流母线首末能量持平时，式(11)是期限与功率上限下的必要下界，用于后续对照闭环结果。
3. **开环解析估计前提**（如式(14)前）：恢复门限完全开启、减发指令未触限、执行器快速跟踪且惯量增发支路为零，避免读者将开环指数估计时间（`13.16 s`）误读为闭环实际持续回补时间（`19.51 s`）。
4. **模型适用范围边界**（集中保留于第 4 节整定边界一节，不在摘要与结论重复）：单区域有功平均模型、公开风场现场试验统计量级、不含空间湍流/尾流及慢速 AGC 频率复归。
